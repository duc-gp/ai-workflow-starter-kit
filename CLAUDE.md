# AI Workflow Starter Kit

## Was ist das
Klonbares Kit für Zielprojekte. Enthält den development-guide (13 Kapitel) + init.sh.

## Benutzung
In ein Zielprojekt klonen, init.sh ausführen. Siehe README.md.

## Konventionen
- development-guide/ wird automatisch von der Eltern-Pipeline aktualisiert
- Nach Guide-Update: commit + push (passiert automatisch)
- init.sh ist idempotent

## Pitfalls
- Dieses Repo liegt physisch in ai-development-workflow/ ist aber git-technisch unabhängig
- Remote: git@github.com:duc-gp/ai-workflow-starter-kit.git
